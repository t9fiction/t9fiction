<h2 align="left">About Me</h2>

I build and operate cloud, datacenter, and enterprise infrastructure. My experience spans networking, systems administration, virtualization, Kubernetes, Docker, Linux, and cloud platforms. I focus on designing scalable, secure, and highly available systems across on-premises and cloud environments while continuously expanding my expertise in cloud engineering, platform engineering, automation, and modern infrastructure operations.

Network and System Administrator with professional experience since 2009. My background includes enterprise networking (routing, switching, VLANs, firewalls, wireless infrastructure), Linux systems administration, datacenter operations, and server infrastructure management. I have extensive hands-on experience with Proxmox, VMware ESXi, storage systems, and virtualization technologies.

On the cloud-native side, I work with Docker, Kubernetes, container orchestration, AWS, GCP, Infrastructure as Code, monitoring, observability, and CI/CD pipelines. I maintain a homelab/datacenter environment for continuous learning and experimentation with emerging infrastructure technologies.

I'm actively pursuing opportunities in Cloud Engineering, Infrastructure Engineering, Platform Engineering, Site Reliability Engineering (SRE), DevOps, Systems Administration, and Enterprise Networking.
